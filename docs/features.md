# راهنمای صفحه‌ها و کارت‌ها

طرح برای پنل افقی ۱۲۰۸×۷۲ ساخته شده و با وزن (نه اندازه‌ی پیکسلی) چیده می‌شود، پس روی ۱۰۲۴×۶۰۰ و
۱۹۲۰×۷۲۰ هم همان نسبت‌ها را نگه می‌دارد. هیچ layout XML وجود ندارد؛ همه‌ی نماها در کد ساخته می‌شوند
(`ui/Views.kt`) تا RTL و اندازه‌ی فونت در یک جا کنترل شود.

## چیدمان

```
┌─────────────── TopBar: ساعت، تاریخ شمسی، دما، نماد GPS/بلوتوث/پخش ───────────────┐
│  ستون چپ    │                کاروسل وسط (ViewPager2)                │  ستون راست  │
│ tiles, nav  │        music ⇄ map ⇄ clock ⇄ vehicle ⇄ weather        │  clock, trip │
├─────────────── Dock: ۶ خانه‌ی قابل ویرایش، کشیدن‌ورها کردن ────────────────────────┤
```

* **ستون‌های کناری** از همان کلاس کارت‌ها ساخته می‌شوند اما با `full = false` (نسخه‌ی فشرده).
* **کاروسل وسط** با سوایپ چپ/راست عوض می‌شود؛ شماره‌ی صفحه با نقطه‌های ریز زیرش مشخص است.
* **Dock**: لمس‌طولانی روی یک خانه → باز کردن برنامه‌ی انتخابگر (`settings/AppPickerActivity`)؛ می‌توانید
  برنامه، اکشن (`open:…`)، یا یک کارت (`card:music`) بگذارید.

## قانون کارت وسط (همان چیزی که خواسته شده)

مغز ماجرا `home/CenterCardCoordinator.kt` است و ترتیب اولویتش این است:

1. **موسیقی** — به‌محض اینکه `MediaHub.state.isPlaying` شود، کارت موسیقی وسط می‌آید و می‌ماند؛ تا پخش
   قطع نشده، نقشه وسط را نمی‌گیرد مگر اینکه ناوبری فعال باشد.
2. **نقشه** — وقتی ناوبری فعال است (برنامه‌ی نشان/گوگل‌مپ پیش‌زمینه است یا مسیر درون‌لانچری برنامه‌ریزی
   شده) کارت نقشه وسط می‌نشیند.
3. **دستی** — سوایپ روی وسط یا اکشن `card:<id>`؛ تا ۷۰۰ میلی‌ثانیه‌ی بعد حالت دستی است و تا
   `manualOverrideSec` (پیش‌فرض ۱۲ ثانیه، در تنظیمات → چیدمان) هیچ‌کدام از دو حالت اول آن را نمی‌شکنند.
4. **در حالت عادی** اولین کارتِ فهرست `center` نشان داده می‌شود.

قفل‌ها: تا ۲۵ ثانیه از آخرین تغییر حالت (پخش/ناوبری) تصمیم عوض نمی‌شود تا صفحه وسط «پینگ‌پنگ» نکند؛
و اگر سوئیچ خودکار در تنظیمات خاموش باشد،هماهنگ‌سازِ مرکزی هرگز حالت دستی را تغییر نمی‌دهد. فقط کارت‌هایی که در
فهرست `center` هستند وارد رقابت می‌شوند — پس اگر نمی‌خواهید نقشه وسط بیاید، آن را از فهرست وسط بردارید.

## کارت‌ها

| شناسه | کارت | خلاصه |
|---|---|---|
| `music` | رسانه | کاور (از اعلان/MediaSession)، عنوان/خواننده، نوار زمان، پخش-توقف، بعدی/قبلی، اسلایدر صدا، خط متن آهنگ اگر اعلان بدهد |
| `map` | نقشه | کاشی زنده، نقطه‌ی آبی با جهت، مقصد ذخیره‌شده، دکمه‌ی «برو» که کار را به نشان/گوگل‌مپ می‌دهد |
| `clock` | ساعت | دیجیتال بزرگ + عقربه‌ای، تاریخ شمسی/میلادی، روز هفته، حلقه‌ی پیشرفت سال و «روزهای باقی‌مانده» |
| `vehicle` | خودرو | سرعت‌سنج، دمای مایع خنک‌کننده، سوخت، ولتاژ، وضعیت درها، فشار باد تایرها، دنده‌ی دنده‌عقب |
| `trip` | سفر | مسافت، زمان در حال حرکت، میانگین و بیشینه‌ی سرعت، مصرف تخمینی؛ ریست روزانه/هفتگی |
| `weather` | هوا | دما، حالت آسمان، حداقل/حداکثر، بارش — از Open-Meteo، کش ۱۵ دقیقه‌ای |
| `tiles` | کاشی‌ها | شبکه‌ی کاشی‌های قابل ویرایش: میان‌بر برنامه، اکشن، کاشی تهویه |
| `nav` | ناوبری | خانه/محل کار، آخرین مقصدها، جست‌وجوی مکان، انتخاب برنامه‌ی مسیریاب |
| `phone` | تماس | آخرین تماس‌ها + شماره‌گیری سریع (با `ACTION_DIAL`؛ هیچ دسترسی تماس لازم ندارد) |
| `camera` | دوربین | میان‌بر برنامه‌ی DVR/دوربین عقب؛ اگر `reverse` از CAN بیاید خودش جلو می‌آید |
| `widget` | ویجت | یک ویجت واقعی AppWidget که می‌توانید از تنظیمات انتخاب/حذف کنید |
| `settings` | تنظیمات | ورودی یک‌لمسه به صفحه‌ی تنظیمات |

## حرکت‌های انگشتی (پیش‌فرض، همه قابل تغییر)

| حرکت | پیش‌فرض |
|---|---|
| سوایپ بالا | برنامه‌های اخیر |
| سوایپ پایین | نوار اعلان |
| سوایپ چپ / راست | کارت بعدی / قبلی وسط (`card_next:prev`) |
| دو ضربه | دستیار صوتی (`voice`) |
| لمس‌طولانی روی پس‌زمینه | همه‌ی برنامه‌ها |

مقادیر همان رشته‌های `action` پایین هستند؛ ویرایش در تنظیمات → حرکت‌ها (`gesturesJson`).

## زبان مشترک اکشن‌ها

هر چیزی که اکشن می‌گیرد (کاشی‌های `tiles`، خانه‌های Dock، حرکت‌های انگشتی، `EXTRA_ACTION` روی لانچر،
`arena.car.CLIMATE` و غیره) با همین قالب است: `verb:argument`.

| اکشن | کار |
|---|---|
| `card:map` | کارت مشخص را وسط بیاور |
| `card_next` / `card_next:prev` | کاروسل وسط را بچرخان |
| `allapps` / `allapps:close` | شبکه‌ی همه‌ی برنامه‌ها |
| `recents` | برنامه‌های اخیر |
| `shade` (همچنین `notifications`, `quicksettings`, `qs`) | نوار اعلان |
| `media` (همچنین `music`, `player`) | آوردن کارت موسیقی |
| `play` / `pause` / `next` / `prev` / `stop` | کنترل پخش (اول MediaSession، بعد کلید رسانه، بعد دکمه‌ی اعلان) |
| `open:com.foo.bar` (همچنین `launch:`, `dvr:`, `camera:`) | باز کردن برنامه |
| `volup` / `voldn` / `volume:55` | صدا |
| `map:home` · `map:work` · `map:recent` · `map:open` · `map:stop` | ناوبری (همچنین `nav:` و `route:`) |
| `theme:day` · `theme:night` · `theme:amoled` · `theme:auto` (همچنین `dark`، `light`) | تم |
| `screen:off` · `screen:dim` · `screen:bright` | صفحه |
| `brightness:70` | روشنایی (نیازمند دسترسی نوشتن تنظیمات) |
| `voice` / `assistant` / `okgoogle` | دستیار صوتی |
| `settings` · `settings:map` | باز کردن تنظیمات (اختیاری: شماره‌ی تب) |
| `lock` / `lock:30` | قفل رانندگی/کودک |
| `sleep` / `idle` | حالت استراحت |
| `climate:ac` · `climate:temp_up` · `climate:fan:2` · `climate:temp=24` | تهویه (بخش `vehicle-bus.md`) |
| `broadcast:com.oem.CAN/door_lock=1` | برودکست خام؛ فرمت `<action>/<key>=<value>` (بدون `/` فقط اکشن؛ مقدار عددی به‌صورت long فرستاده می‌شود) |
| `keyevent:24` | کلید ورودی (با `KEYCODE_…` یا شماره‌ی کلید) |
| `home` | صفحه‌ی خانه‌ی سیستم |
| `com.foo.bar` (بدون دونقطه) | همان `open:` — هر رشته‌ی ناشناخته به‌عنوان نام بسته آزمایش می‌شود |

نکته: لانچر عمداً سخت‌گیر نیست — `wallpaper:`، `prefs:`، `drawer:`، `skip:`، `childlock:` و امثال آن به
همان معادل‌های بالا نگاشت می‌شوند، چون این رشته‌ها اغلب از ماکروهای ازپیش‌نوشته‌ی Tasker/MagicDroid
کپی می‌شوند.

## پیش‌تنظیم‌های چیدمان

تنظیمات → چیدمان → «پیش‌تنظیم»: `agama` (پیش‌فرض، نزدیک به ساختاری که خواستید)، `wide` (نقشه بزرگ،
ستون‌های کم)، `minimal` (فقط ساعت و موسیقی)، `carplay` (نقشه + موسیقی + تماس). هر کدام فقط فهرست
کارت‌های `center`/`left`/`right`، گردی گوشه‌ها و شفافیت کارت‌ها را عوض می‌کنند.

## صفحه‌ی همه‌ی برنامه‌ها

حروف اول، جست‌وجوی زیررشته‌ای روی نام و نام بسته، پنهان‌کردن برنامه‌های غیرقابل‌اجرا، مرتب‌سازی
الفبا/پرکاربردترین، و پوشه‌های سیستمی/تنظیماتِ دستگاه که روی هده‌یونیت‌ها زیاد پیدا می‌شوند. لمس‌طولانی →
«پنهان کردن» / «جزئیات برنامه» / «افزودن به Dock».

## بنر تماس

`services/CallOverlayService` با `TYPE_APPLICATION_OVERLAY` یک نوار کوچک بالا-وسط می‌گذارد: شماره/نام،
پاسخ، قطع. وقتی تماس فعال است `ACTION_INCOMING_CALL`/`OFFHOOK` می‌آید و بنر تا پایان تماس می‌ماند.
روشن/خاموشش: تنظیمات → رفتار → «نوار تماس روی صفحه». دسترسی «نمایش روی سایر برنامه‌ها» لازم است؛ دسترسی مخاطب **نمی‌خواهد** (نام از `EXTRA_PHONE_NUMBER` و
`ContactLookup` اختیاری خوانده می‌شود و اگر دسترسی نباشد فقط شماره نمایش داده می‌شود).

## قفل رانندگی

`lock:<ثانیه>` یا سوئیچ تنظیمات: تا وقتی سرعت از آستانه بالا باشد، ویرایش چیدمان و Dock قفل است و
لمس‌های تصادفی روی کارت‌ها اثر نمی‌کنند. منبع سرعت، GPS یا `speed` روی گذرگاه خودرو است.
